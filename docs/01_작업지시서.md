## 1. 작업 목적

행사장 가로형 스크린(DID/LED/프로젝터)에 송출할 **안내 화면**과 **발표 사이 간지(브릿지) 화면**을 하나의 HTML 파일로 제작한다.
운영자가 키보드·클릭 한 번으로 화면을 전환하고, 대기 시간에는 자동 순환하며, 현재 시각·다음 프로그램을 실시간으로 보여 주는 것이 목표다.

## 2. 범위

### 2-1. 포함 (In scope)

| 그룹 | 화면 | 수량 |
|---|---|---|
| A | 공통 대기화면 (Idle) | 1 |
| B | 행사 안내 | 1 |
| C | 행사 프로그램 안내 | 1 (오전/오후 2열 한 화면) |
| D | 경품 안내 (목록) + 경품 개별 카드 | 1 + 4 |
| E | 행사 시작·재개 안내 (카운트다운) | 2 (시작 / 오후 재개) |
| F | 진행 안내 — 에티켓 (휴대폰 무음, 유튜브 촬영 고지) | 1 |
| G | 섹션별 간지 (개회사 ~ 경품추첨·폐회), 영상 축사·축전 낭독 화면 포함 | 16 |
| H | 오찬·네트워킹 안내 | 1 |

총 **25화면 내외**, 단일 `index.html` + `assets/` 폴더로 납품.

### 2-2. 제외 (Out of scope)

- 발표 본편 슬라이드 (각 발표자 PPT)
- 캐노피 DID 인쇄용 이미지 재제작 (이미 `캐노피 DID.jpg` 확정, 본 작업의 디자인 기준으로만 사용)
- 실시간 추첨 프로그램(난수 추첨 로직). 경품추첨은 별도 진행, 본 화면은 "추첨 안내"만 담당

## 6. 화면별 요구사항

### A. 공통 대기화면 (`#idle`)
- 캐노피 DID와 동일 구성: 좌 행사명·슬로건·일시·장소·서비스 3종, 우 WELCOME + 대형 현재 시각
- 하단에 **다음 프로그램** 티커 (현재 시각 기준 자동 계산: "11:20 TheOther.Space 2.0 · 고상현 본부장")
- 60초마다 `행사 안내 → 프로그램 안내 → 경품 안내 → 에티켓` 순으로 자동 순환(설정값 `IDLE_ROTATE_SEC`). 운영자가 아무 키나 누르면 순환 중지

### B. 행사 안내 (`#about`)
- 행사명, 슬로건(제주가 만들고 세계인이 사용한다 / Made in Jeju, Used Worldwide), 일시, 장소, 행사장 안내(호텔 2층 크리스탈홀)
- 런칭 서비스 3종: Kstory.ai(AI 동화 창작 서비스) · theOther.Town(배움과 연구의 가능성을 넓히는 AI) · TheOther.Space 2.0(경계를 넘어서는 AI 업무환경)
- 공동주최·주관 로고 밴드

### C. 프로그램 안내 (`#program`)
- 타임테이블 전체를 **좌 오전(10:00~13:00) / 우 오후(13:00~15:00)** 2열로 한 화면에 표시. 페이지 전환 없음
- 현재 시각에 해당하는 행 **하이라이트** + 하단 진행 바
- 지난 세션은 70% 투명도

### D. 경품 안내 (`#prize`, `#prize/1`~`#prize/4`)
- 목록 화면: 1등 HP 노트북 · 2등 삼성 스마트워치 · 3등 삼성 태블릿 · 4등 삼성 무선이어폰 + "15:00 행사 종료 후 경품추첨" + 참여 QR (`image4.jpeg`, 샘플 pptx 동봉)
- 개별 카드 4장: 좌 등수 대형 숫자 + 제품명, 우 제품 이미지. 추첨 진행 중 사용
- 추첨 시 `#prize/4 → #prize/1` 순서로 역순 진행 (4등부터)

### E. 행사 시작·재개 안내 (`#start`, `#resume`)
- `#start`: "잠시 후 행사가 시작됩니다" + 10:50 목표 카운트다운(mm:ss) + 착석 안내
- `#resume`: "오후 프로그램이 곧 재개됩니다" + 13:00 목표 카운트다운
- 목표 시각은 DATA에서 수정 가능. 카운트다운 0 도달 시 "곧 시작합니다" 펄스 애니메이션

### F. 진행 안내 — 에티켓 (`#etiquette`)
- 3개 항목 가로 카드(3열):
  1. 휴대폰은 무음 또는 진동으로
  2. 본 행사는 **유튜브 촬영 및 송출** 중입니다 (촬영 동의 고지)
  3. 사진 촬영은 자유, 단 플래시는 자제
- 문구는 운영팀 최종 확인 후 확정 (촬영 고지는 법무 검토 문구로 교체 가능하도록 DATA 분리)

간지 공통 레이아웃: 풀블리드 비주얼(피사체 우측), 좌측 55% 텍스트 — `SESSION 02` 라벨 / 세션명(메가 타이틀) / 발표자 이름·직함·(외부만) 소속. **간지에는 시간을 표시하지 않는다**(진행 지연 시 혼선 방지). 표의 시간은 운영 참고용.

**발표자 표기 규칙**
- 틸론소프트 소속 발표자(차진욱, 민정식, 고상현, 이춘성, 오은영, 박나연, 홍재영, 최백준, 김기환)는 **이름 + 직함만** 표시하고 회사명을 쓰지 않는다. 예: `민정식 차장`
- 외부 발표자·내빈은 **이름 + 직함 + 소속**을 표시한다. 예: `박철민 팀장 · KT클라우드`, `강주경 회장 · 사단법인 제주인공지능산업협회`
- DATA에서는 `org`를 비워 두면 소속 줄이 렌더링되지 않는다.

## 7. 인터랙션 & 운영 사양

| 조작 | 동작 |
|---|---|
| `→` / `Space` / `PageDown` | 다음 화면 (큐시트 순서) |
| `←` / `PageUp` | 이전 화면 |
| `0` | 대기화면 `#idle` |
| `1`~`9` | 바로가기: 1 행사안내, 2 프로그램, 3 경품, 4 시작안내, 5 재개안내, 6 에티켓, 7 오찬, 8 경품추첨 카드, 9 폐회 |
| `S` 후 숫자 두 자리 | 섹션 간지 직접 이동 (예: `S` `0` `7` → 축사 I) |
| `F` | 전체화면 토글 |
| `H` | 운영자 오버레이(화면 목록 그리드) 토글. 클릭으로 이동. 송출 화면에는 보이지 않도록 반투명 좌하단 |
| `B` | 블랙아웃(검은 화면) 토글 |
| URL 해시 | `index.html#s/3` 처럼 직접 진입 가능. 새로고침해도 현재 화면 유지 |

- 화면 전환: 0.6s 크로스페이드 + 텍스트 아래에서 위로 24px 슬라이드 인 (stagger 80ms)
- 모든 애니메이션 `prefers-reduced-motion` 존중
- 운영자 보조: 우상단 현재 시각 외에 좌하단 아주 작은 글씨로 현재 화면 ID 표시 (송출 시 `?clean=1`로 숨김)
